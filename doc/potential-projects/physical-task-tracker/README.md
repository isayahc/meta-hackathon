# Physical Task Tracker

## Problem statement

Long-running physical tasks — home renovations, construction punch lists,
vehicle restorations, garden or farm projects, rehab and training programs —
stretch across days, weeks, or months, with work happening in scattered
sessions. Between sessions, state lives in people's heads: what got finished,
what was half-done, what the room looked like before the drywall went up,
which step comes next.

Existing tools fail this use case. Todo apps track intentions, not physical
state — checking off "paint bedroom" says nothing about which walls are primed.
Photos pile up unsorted in camera rolls with no link to the task they document.
Handoffs (to a partner, a contractor, your future self after a two-week break)
require re-learning the project from scratch.

The gap is a tracker built for tasks that change the physical world: one that
records the state of the work itself across sessions, not just a checklist.
Progress photos tied to steps, visual before/after comparison of the same spot
(SAM-style segmentation can isolate exactly what changed), and continuity so
any session starts with "here is where things stand" instead of archaeology.
