# Sample clips (synthetic)

`farm-rows.mp4` and `site-pour.mp4` are synthetic pipeline fixtures generated
locally with ffmpeg (`testsrc2` segments, hue-shifted per segment, 6s each).
They carry container `creation_time` tags (2026-10-20 / 2026-10-22) so the
recorded-date path is exercisable without a camera. Not real footage: the
recorded demo still needs phone video.
